# Changelog

## 0.1.0 - 2026-10-29
- First release: `/btw` opens a floating window over the transcript for one-off side questions while the main agent keeps working
- Answers stream in as markdown, scrollable with the wheel or page up / page down
- Each finished btw is saved into the session as its own `btw`-labelled branch, so it shows up in `/tree` and can be continued from there
